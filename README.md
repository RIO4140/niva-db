# NivaDB — محرك قواعد بيانات بلغة Niva

محرك قواعد بيانات مستقل ومفتوح، مكتوب بلغة البرمجة العربية **Niva** من الصفر.
لا يستخدم PostgreSQL ولا SQLite ولا أي محرك خارجي — كل مكوناته الأساسية بلغة Niva،
وRust مقتصر على بيئة تشغيل اللغة نفسها.

## الحالة

**v0.1.0-dev — المرحلة الأولى (Core) قيد البناء.**
يعمل محليا دون اتصال بالإنترنت. انظر `docs/خطة-المرحلة-الأولى.md` للتصميم
و`docs/تقييم-القدرات.md` لتقييم ما تستطيعه لغة Niva اليوم وما ينقصها — بالدليل من الكود.

## المراحل السبع

1. **Core** — قاعدة محلية: جداول، إدخال واسترجاع، تعديل وحذف، فهرسة، حفظ دائم.
2. **المعاملات** — ACID، WAL، MVCC، استعادة بعد الأعطال.
3. **محرك استعلامات متقدم** — JOIN، استعلامات فرعية، مخطط ومحسّن استعلامات.
4. **خادم شبكة** — اتصال عن بعد، مصادقة، TLS.
5. **بنية موزعة** — عقد متعددة، تكرار، تقسيم، تحمل أعطال.
6. **NivaDB Studio** — واجهة رسومية وإدارة ومراقبة ونسخ احتياطي.
7. **تحسين** — اختبارات ضغط ومقارنة أداء منشورة (بعد القياس، بلا أرقام دعائية مسبقة).

## البناء والتشغيل

```sh
# 1 — تمهيد بيئة التشغيل (ينزّل ثنائي Niva المثبّت دون استنساخ مستودع اللغة)
sh tools/تمهيد.sh

# 2 — شغّل المثال الأول
نيفا src/مثال-أول.نيفا

# 3 — شغّل الاختبارات
sh tools/شغّل-الاختبارات.sh
```

لا حاجة لاستنساخ مستودع لغة Niva كاملا. التمهيد ينزّل ثنائي Runtime المثبّت
من إصدارات مستودع `RIO4140/niva` (انظر `RUNTIME-COMPAT`).

## القواعد

- المكونات الأساسية بلغة Niva؛ ويُمنع Python في المنتج؛ ويُمنع أي محرك قواعد
  بيانات خارجي باعتباره المحرك الفعلي.
- لا انتقال لمرحلة تالية قبل نجاح اختبارات المرحلة السابقة.
- كل مكون موثّق ومختبَر مستقلا: Unit وIntegration وStress وRecovery.
